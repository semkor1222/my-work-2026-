# Мой учебный проект

## Источник данных
Собственная таблица Google Sheets. Данные подготовлены для учебного проекта по технологиям хранения данных.

## Файлы проекта
- `data.csv` — таблица с пятью пунктами, датами и статусами выполнения.
- `data_v1.csv` — исходная версия данных для практической работы №3.
- `data_v2.csv` — расширенная версия данных для практической работы №3.
- `data_v3.csv` — структурированная версия данных со столбцом «Категория».

## Результат
Выполнено **60 %** пунктов: 3 из 5 задач имеют статус «выполнено».

## История версий данных
- `v1.0` — исходный набор из 5 записей.
- `v1.1` — добавлены 3 записи, всего 8.
- `v2.0` — добавлен столбец «Категория».

## Назначение проекта
Проект демонстрирует создание, хранение и версионирование учебных данных в GitHub.
